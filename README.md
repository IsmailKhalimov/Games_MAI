## Краткий запуск

1. Открыть папку `My project` в Unity Hub (Unity `6000.4.6f1`).
2. Открыть сцену `Assets/Scenes/Prototype.unity`.
3. Нажать `Play`.

## Управление

- `W/A/S/D` — движение
- Мышь — камера
- `E` — поставить метку на объект
- `F` — активировать все метки
